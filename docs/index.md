# Rapid Upskilling Pipeline

This guide teaches a method for building an [upskilling program](glossary.md#upskilling-program). It comes with sample prompts and scripts. The method is a framework of five stages. Its premise is that AI does the volume work while people keep the judgment calls, staying [in the loop](glossary.md#human-in-the-loop) wherever a decision matters. It is written to be platform-neutral, so you can adapt it to your [agentic platform](glossary.md#agentic-platform).

The **[reference implementation](glossary.md#reference-implementation)** is the original program and tooling this guide was written from.

## What each stage covers

The five [stages](glossary.md#stage) run in order.

1. Knowledge acquisition: explores a subject and extracts what the sources say into a [knowledge base](glossary.md#knowledge-base) ordered by prerequisites.
2. Content development: drafts chapters from a fixed template, with objectives, labs, and exam-style test questions.
3. Review and verification: runs scripted checks for unsupported claims, and specifies a review by experts.
4. AI-tutor coaching: sets the rules for an AI tutor, with coaching protocols, learner guardrails, and a catalog of misconceptions (common wrong beliefs) for each chapter.
5. Assessment development: drafts test questions tagged to the blueprint, the program's own plan, with wrong answers built from known misconceptions.

The [Pipeline overview](pipeline-overview.md) gives the full picture.

## Where to start

Start with [How to use this guide](how-to-use-this-guide.md). It says what you need and how each page is laid out. Every stage uses one small, fictional program, the [running example](running-example.md).

## What this guide is

This guide is a method, not a product. It describes a design and how the reference implementation was run, as of September 2026. It makes no claims about results.
