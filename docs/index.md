# Rapid Upskilling Pipeline

This site will teach you how to build an upskilling program with AI help, one stage at a time. Each stage will have a written procedure, prompts, and scripts that you can copy and adapt to the agentic platform you use. Steps that need a human decision will be marked.

The site is under construction. Pages are drafts, and most planned pages do not exist yet. To help, start with [Contributing](contributing/index.md).
