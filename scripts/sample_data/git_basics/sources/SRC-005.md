# Quick cheat sheet: sending and getting changes

Written for the new hires. Keep this open in a tab for your first few weeks!

## Getting a copy

`git clone URL` makes a local copy of a shared repository, normally with its history. It also remembers where the copy came from, under the name `origin`. Run `git remote -v` if you ever forget the address.

## Getting other people's work

`git fetch` grabs the newest commits from the server and updates your remote-tracking branches, such as `origin/main`. Your own branches stay where they were.

`git pull` is the friendly one. It only downloads the latest changes from the server. It never touches the files you are working on, so you can run it whenever you like without thinking about it. Once it has finished, look at what came down and decide for yourself when to bring it into your branch.

To see whether anything new is waiting, `git status` will say that your branch is behind (or diverged, if you also have local commits of your own), if it tracks a remote branch. It only knows what you last downloaded, though, so download first.

## Sending your work

`git push origin BRANCH` uploads your commits to the server. A common reason a push is rejected is that somebody else got there first. Get their changes, deal with any conflicts, and push again.

Starting a brand-new branch? Use `git push -u origin BRANCH` the first time. The `-u` remembers the pairing, and after that a plain `git push` on that branch usually knows where to go.

## Rules of thumb

- Commit early and often, in small pieces.
- Run `git status` before you commit and before you push.
- Check your work with `git log --oneline` so you know what you are about to send.
- Avoid pushing half-finished work to a branch that other people build on.
- If a message confuses you, ask. Questions are welcome.

## Two things people forget

Committing is local. Your commits stay on your machine until you push them, so an unpushed commit is not a backup.

And a push sends commits, not uncommitted edits. If you want a change to travel, commit it first.
